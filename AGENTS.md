# AGENTS.md — правила работы в этом репозитории

## Что это

NetSketch: веб-приложение, которое строит DWG/PDF/PNG по рукописному эскизу
тепловой или газовой сети. Пользователь работает с веб-формой; модель зрения
и генератор чертежей скрыты внутри.

## Быстрый цикл

```powershell
$env:PYTHONPATH = "$PWD\.pydeps"
$env:PYTHONIOENCODING = "utf-8"
python -m netsketch doctor
python tools\smoke_test.py          # ~1 мин, гоняет OCS
python tools\api_test.py http://127.0.0.1:8770
```

Зависимости лежат в `.pydeps` (не в системном Python). Ставятся так:

```powershell
python -m pip install --target .pydeps -r requirements.txt
```

## Инварианты, которые нельзя ломать

1. **Один источник геометрии.** `layout.build_scene()` → `Scene` в мм листа.
   DXF и PDF/PNG строятся только из неё. Нельзя рисовать PDF «отдельно».
2. **Единицы — миллиметры листа, 1:1.** Масштаб применяется при пересчёте
   пикселей эскиза, а не при печати.
3. **Три состояния достоверности.** `CONFIRMED` / `DERIVED` / `ASSUMED`.
   Домысленное — только на слой `ASSUMED` и в примечания.
4. **Модель не рисует.** Любая «умная» логика заканчивается на `model.json`.
   Черчение — детерминированный код.
5. **Ошибки не глотать.** Не удалось конвертировать DWG — задача `error` с
   текстом причины, а не «успех без файла».

## Где что менять

| Задача | Файл |
|---|---|
| новый тип сети | `config.BUILTIN_NETWORK_TYPES`, `styles.NETWORK_LAYERS`, `knowledge/<тип>.md` |
| новый символ | `symbols.draw_symbol`, `model.ELEMENT_TYPES` |
| поле штампа / рамка | `sheets.py` |
| масштаб и компоновка | `layout.py` (`_pick_scale`, `build_scene`) |
| промпт распознавания | `prompts.py`, `knowledge/*.md` |
| HTTP-роуты | `server.py` |
| интерфейс | `web/index.html`, `web/styles.css`, `web/app.js` |

## Стиль кода

* Python 3.11+, стандартная библиотека где возможно; внешние — только
  `ezdxf`, `matplotlib`, `Pillow`, `PyMuPDF`.
* Аннотации типов, `from __future__ import annotations`.
* Комментарии и тексты для пользователя — по-русски; имена в коде — английские.
* Никаких «магических» абсолютных путей: всё через `config.Settings`.

## Грабли, уже проверенные

* **BOM в JSON.** Файлы, записанные PowerShell 5.1 (`Set-Content -Encoding UTF8`),
  содержат BOM. Читать пользовательские JSON только как `utf-8-sig`.
* **Временные папки.** Системный `%TEMP%` может быть закрыт песочницей;
  тесты и кэш держать внутри проекта (`data/`, `.cache/`).
  `MPLCONFIGDIR` уже перенаправлен в `.cache/matplotlib`.
* **Open CAD Studio `--export`** понимает только `dwg/dxf/dwt` — PDF и PNG
  делает свой рендер, не просите у OCS PDF.
* **Повторное сохранение** в существующий DWG: файл удаляется перед
  конвертацией (иначе возможен диалог подтверждения).
* **Кириллица в DXF** — стиль `NS_GOST` с Arial; `Ø` рендерится нормально.
* **Текст в matplotlib** шире, чем в Arial: при тесной компоновке проверять
  предпросмотр, а не только DWG.

## Определение готовности

`tools/smoke_test.py` зелёный, `tools/api_test.py` доходит до `done`,
PNG просмотрен глазами, DWG открывается. Только после этого говорить
«готово».
