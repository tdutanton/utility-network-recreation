# ГОСТ 21.710-2021: рабочая выжимка (наружные сети газоснабжения)

Полное название: «Система проектной документации для строительства. Правила
выполнения рабочей документации наружных сетей газоснабжения».

| Параметр | Значение |
|---|---|
| Статус | действует (МГС, РФ) |
| Принят | МГС, протокол № 138-П от 19.03.2021; приказ Росстандарта № 777-ст от 24.08.2021 |
| Введён | 01.09.2021 |
| Взамен | ГОСТ 21.610-85 «Газоснабжение. Наружные газопроводы. Рабочие чертежи» |
| Разработан | АО «ЦНС», ТК 465 «Строительство» |
| Издание | ФГБУ «РСТ», 2021 |
| МКС | 01.100.30 |

Поправки (ИУС № 4 2022, ИУС № 7 2023) касаются таблицы согласования
(Казахстан, Азербайджан) — на правила черчения не влияют.

Ниже — выжимка по официальному изданию; номера пунктов сохранены.

## 1. Область применения

Состав и правила выполнения рабочей документации **наружных газопроводов**
(подземных, надземных) сетей газораспределения или газопотребления для
природного, попутного нефтяного, искусственного и смешанного газа с
избыточным давлением **не более 1,2 МПа**, используемого как топливо и сырьё.

Внутренние системы — ГОСТ 21.609-2014, не этот стандарт.

## 3. Термины

* **наружный газопровод** — подземный и (или) надземный газопровод сети
  газораспределения/газопотребления вне зданий, до внешней грани наружной
  конструкции здания;
* **подземный** — ниже поверхности земли или по поверхности в обваловании;
* **надземный** — над поверхностью земли или по поверхности без обвалования;
* **сеть газораспределения** — комплекс от отключающего устройства на выходе
  ГРС до отключающего устройства на границе с сетью газопотребления;
* **сеть газопотребления** — комплекс от границы сетей до отключающего
  устройства перед газоиспользующим оборудованием на одной площадке.

## 4. Общие положения

**4.2. Состав рабочей документации:**

* рабочие чертежи для строительных и монтажных работ — основной комплект
  **марки ГСН**;
* эскизные чертежи общих видов нетиповых изделий (ГОСТ 21.114);
* спецификация оборудования, изделий и материалов;
* локальная смета (при необходимости).

**4.3. Состав основного комплекта ГСН:**

* общие данные по рабочим чертежам;
* планы газопроводов;
* продольные профили газопроводов.

При большой насыщенности планов — выносные элементы (фрагменты, узлы).
Для надземных газопроводов при необходимости — разрезы и изображения
(схемы) в аксонометрии по ГОСТ 2.317.

**4.4. Обозначения.** Газопроводы, элементы, арматура — условными
графическими обозначениями по ГОСТ 21.206 и ГОСТ 21.205 либо упрощёнными
изображениями в масштабе чертежа. Если видимых участков на чертеже нет,
проектируемые подземные газопроводы допускается показывать сплошной толстой
основной линией с пояснениями в общих данных или на листах.
Буквенно-цифровые обозначения газопроводов — по **ГОСТ 21.205-2016**
(таблица 20).

**4.5. Числа.** Длины, расстояния между колодцами, опорами, углами
поворота, отметки уровней (высоты, глубины) — в **метрах с двумя
десятичными знаками**, отделёнными **запятой**. Диаметры и толщины стенок —
в миллиметрах, наносят по ГОСТ 21.206-2012 (3.11).

**4.6.** Угловые размеры — в градусах, минутах, при необходимости секундах,
с обозначением единицы: `4°`, `4°30'`, `12°45'30"`.

**4.7.** Уклон — числом в **промилле без обозначения единицы**.

**4.8.** Система координат и высотных отметок — как на топографическом плане.

**4.9. Марки элементов** (таблица 1) + порядковый номер в пределах
газопровода, например `УП1`, `УП2`:

| Элемент | Марка |
|---|---|
| Колодец | ГК |
| П-образный компенсатор | КП |
| Угол поворота | УП |
| Неподвижная опора | Н |

**4.10. Масштабы (таблица 2):**

| Изображение | Масштаб |
|---|---|
| Планы газопроводов | 1:200, 1:500, 1:1000, 1:2000 |
| Продольные профили: по горизонтали | 1:200, 1:500, 1:1000, 1:2000 |
| Продольные профили: по вертикали | 1:50, 1:100 |
| Фрагменты и узлы | 1:10, 1:20, 1:50, 1:100 |

Масштаб — в графе 4 основной надписи по форме 3 ГОСТ 21.101 (приложение Д).
Если на листе несколько изображений в разных масштабах — масштаб в круглых
скобках рядом с наименованием каждого. Масштабы профиля по горизонтали и
вертикали — **слева от профиля, над боковиком таблицы** (пример:
`1:500 по горизонтали`, `1:100 по вертикали`).

**4.11. Делению на участки** (на отдельных листах) — в графе 4 указывают
наименование участка с привязкой к пикетам. Пример — `План ПК0 —
ПК50+10,00`; `Профиль Г3 ПК0 — ПК75+40,00`.

## 5. Общие данные по рабочим чертежам

**5.1.** По ГОСТ 21.101.

**5.2.** Ведомость спецификаций по ГОСТ 21.101 в составе общих данных
**не выполняют**.

**5.3. Общие указания** — дополнительно: категория газопровода, требования
по монтажу, испытаниям, условиям прокладки, лакокрасочному покрытию и
защитному (изоляционному) покрытию.

## 6. Планы газопроводов

**6.1.** Подоснова — рабочие чертежи генеральных планов, автомобильных
дорог и железнодорожных путей или топографические планы; допускается
цифровая модель местности.

**6.2. На планах наносят и указывают:**

* существующие и проектируемые здания (сооружения) упрощёнными контурными
  очертаниями **сплошной тонкой** линией;
* проектируемые и существующие газопроводы и их элементы по 4.4;
* координатную привязку элементов или привязку к координационным осям
  зданий, к наружным стенам; при необходимости — номера пикетов (ПК) и
  привязки к ближайшим пикетам;
* числовые значения углов поворота, **кроме 90°**; допускается указывать их
  только в графе «Развёрнутый план» таблицы под профилем;
* инженерные сети другого назначения, влияющие на прокладку;
* диаметры и толщины проектируемых газопроводов **до и после** точек их
  изменения;
* сооружения на газопроводах: колодцы, конденсатосборники,
  контрольно-измерительные пункты, электрические перемычки,
  электроизолирующие соединения, установки электрохимической защиты;
* охранную зону газопроводов (при необходимости).

**6.3.** Планы — на отдельных листах или совместно с продольными профилями.

**6.4.** Пример — рисунок А.1 (приложение А).

## 7. Продольные профили газопроводов

**7.1.** Профиль — развёртка по осям газопроводов.

**7.2. На профиле наносят и указывают:**

* поверхность земли: проектную — сплошной толстой основной, фактическую —
  сплошной тонкой;
* уровень грунтовых вод — тонкой штрихпунктирной линией;
* пересекаемые дороги, железнодорожные и трамвайные пути, кюветы, другие
  подземные и надземные сооружения — упрощёнными контурами сплошной тонкой
  линией; влияющие коммуникации — с габаритами и высотными отметками;
* проектируемый газопровод — сплошной толстой основной линией; двумя
  линиями, если диаметр в масштабе **2 мм и более**;
* колодцы, коверы, эстакады, отдельно стоящие опоры и другие сооружения —
  упрощёнными контурами наружных габаритов сплошной тонкой линией;
* данные о грунтах — по ГОСТ 21.302 (колонки в точках выработок или по
  трассе);
* отметки **верха трубы** для подземного газопровода и **низа трубы** — для
  надземного;
* глубину траншеи от проектной и фактической поверхности земли;
* футляры с диаметрами, длинами и привязками к оси дорог, сооружениям или
  пикетам;
* обозначения инженерно-геологических выработок (разведочных скважин).

**7.3. Таблица под профилем.** Боковик — форма 1 (подземная прокладка) или
форма 2 (надземная).

Форма 1 (подземный):

| Строка | Содержание |
|---|---|
| Отметка земли проектная, м | проектная поверхность |
| Отметка земли фактическая, м | фактическая поверхность |
| Отметка дна траншеи, м | низ траншеи |
| Отметка верха трубы, м | верх трубы |
| Глубина траншеи, м | от поверхности до дна |
| Обозначение трубы и тип изоляции | марка, стенка, изоляция |
| Основание | естественное/искусственное, подушка |
| Уклон, ‰; длина, м | наклон участка линией, над ней ‰, под ней длина |
| Расстояние, м | между точками |
| Развёрнутый план | ось газопровода с сооружениями |

Форма 2 (надземный): отметка земли проектная и фактическая, **отметка низа
трубы**, обозначение трубы и тип изоляции, уклон ‰ и длина, расстояние,
развёрнутый план.

Примечание к таблице: в графе «Уклон, ‰; длина, м» прямолинейные участки
показывают линиями с наклоном, соответствующим профилю; над линией — уклон,
под линией — длина участка.

Допускается дополнять таблицы пикетами, высотой опор, характеристиками
грунтов (просадочность, набухание, коррозионная агрессивность), шкалой
отметок.

**7.4.** Отметки дна траншеи — в характерных точках: пересечения с
дорогами, путями, коммуникациями, влияющими сооружениями.

**7.5.** Пример — рисунок Б.1.

## 8. Спецификация оборудования, изделий и материалов

**8.1.** К комплекту ГСН — по ГОСТ 21.110 с учётом настоящего стандарта.

**8.2. Порядок групп** (для каждого газопровода):

1. оборудование;
2. элементы сооружений на газопроводах из сборных конструкций;
3. трубопроводная арматура;
4. другие изделия;
5. закладные конструкции (отборные устройства для КИП);
6. трубы для газопроводов;
7. изоляционные конструкции;
8. материалы.

Внутри группы — по возрастанию основных параметров (тип, марка, диаметр).

**8.3. Единицы измерения:**

| Что | Единица |
|---|---|
| оборудование и изделия | шт. |
| трубы для газопроводов | м |
| элементы газопроводов (фасонные части) | шт. |
| изоляционные материалы | м³ |
| материалы покрытий и защиты | м² |
| другие материалы | кг или т |

## Отличия от 21.609 (шпаргалка)

| Вопрос | 21.609 (внутри) | 21.710 (снаружи) |
|---|---|---|
| Марка комплекта | ГСВ | ГСН |
| Основные листы | планы, разрезы, схемы, установки | планы, продольные профили |
| Схемы | обязательны (аксонометрия) | только для надземных, при необходимости |
| Числа | отметки по ГОСТ 21.101 | метры, 2 знака, запятая; уклоны ‰ |
| Марки элементов | `Ст1`, `1Г3`, `1Г3.1` | `ГК1`, `УП1`, `Н`, `КП` |
| Спецификация | 6 групп (оборудование…материалы) | 8 групп (оборудование…материалы) |
| Примеры | В.1–В.3, Г.1, Г.2, Д.1–Д.3, Е.1 | А.1 (план), Б.1 (профиль) |
