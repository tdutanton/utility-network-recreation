# Как устроено черчение (и как его менять)

## Один источник геометрии — два выхода

`layout.build_scene()` строит `Scene` — список примитивов **в миллиметрах
листа** (1 единица = 1 мм бумаги). Дальше:

* `dxfout.save_dxf()` — сцена → DXF (ezdxf);
* `render.render_scene()` — сцена → PDF/PNG (matplotlib).

Поэтому PDF и DWG совпадают. Единицы листа в мм снимают классическую
проблему «нарисовал в метрах — получил пустой PDF».

## Слои

База: `FRAME`, `TITLE`, `TEXT`, `DIM`, `LEGEND`, `TABLE`, `AXIS`,
`ASSUMED` (пурпурный, штриховой — только домысленное), `HIDDEN`.

Газ: `GAS_MAIN`, `GAS_BRANCH`, `GAS_INLET`, `GAS_SLEEVE`, `GAS_EQUIP`,
`GAS_WELL`, `GAS_LABEL`.
Тепло: `HEAT_SUPPLY` (красный), `HEAT_RETURN` (синий), `HEAT_BRANCH`,
`HEAT_SLEEVE`, `HEAT_EQUIP`, `HEAT_WELL`, `HEAT_LABEL`.

Толщина линии растёт с диаметром: ≤50 → 0,35; ≤150 → 0,5; ≤400 → 0,7; иначе 0,9 мм.

Новый тип сети: добавить запись в `styles.NETWORK_LAYERS`, ветку в
`styles.layer_of`, `config.BUILTIN_NETWORK_TYPES` и `knowledge/<тип>.md`.

## Лист

`sheets.py`: A4 210×297 … A0 841×1189 (портрет), альбомная — поворот.
Рамка: слева 20 мм, остальные 5. Штамп 185×55 в правом нижнем углу:
таблица изменений 65 мм + организация, стадия/лист/листов/масштаб,
наименование, подписи.

Поле плана: `Sheet.plan_area(legend_width=…)` — рамка минус штамп и
колонка легенды (72…130 мм в зависимости от ширины листа).

## Масштаб

`_estimate_mm_per_px` → `_pick_scale` (ряд 50…5000). Выбирается самый
крупный стандартный масштаб, при котором план влезает в поле.

Принудительно: `--scale 500` или поле `scale` в запросе API.

## Символы

`symbols.draw_symbol()` рисует примитивами (линии, треугольники, круги),
без блоков DWG: так символы можно масштабировать и они не «плывут» при
редактировании. Базовый размер 4–5 мм листа.

Добавить символ: ветка в `draw_symbol` + запись в `model.ELEMENT_TYPES`
и (для подписи в легенде) — русская подпись.

## Легенда, спецификация, примечания

Правая колонка, сверху вниз. Легенда — использованные типы + явная
`legend`. Спецификация — `specification`, иначе агрегат по диаметрам.
Примечания — `notes` + `assumptions` + предупреждения раскладки.

## Где что менять

| Задача | Файл |
|---|---|
| размеры/поля штампа | `sheets.py` |
| слои, цвета, типы линий | `styles.py` |
| внешний вид символов | `symbols.py` |
| правила раскладки, подписи | `layout.py` |
| шрифт, толщины в PDF | `render.py` |
| атрибуты DXF | `dxfout.py` |
| конвертация DWG | `dwg.py` |
