# Проверка чертежа перед выдачей

## Автоматически

```powershell
python tools\smoke_test.py      # сборка + чтение DWG обратно + размер PDF
python tools\api_test.py        # HTTP API целиком
python -m netsketch doctor      # окружение
```

`smoke_test` проверяет:

- DWG/PDF/PNG/DXF созданы и не пустые;
- PDF — ровно одна страница нужного формата (A4 297×210, A3 420×297, …);
- PNG содержит штрих (не белый лист);
- DWG открывается обратно Open CAD Studio и содержит > 50 сущностей.

## Глазами (обязательно)

1. Открыть PNG-предпросмотр (он же основа PDF).
2. Сверить с эскизом:
   - форма трассы и число поворотов;
   - все диаметры и длины;
   - колодцы/камеры, арматура на своих местах;
   - подписи с эскиза не потеряны.
3. Проверить лист:
   - план не заходит на штамп и рамку;
   - текст не лежит на линиях;
   - легенда совпадает с тем, что нарисовано;
   - масштаб в штампе соответствует полю чертежа.

## Чек-лист

- [ ] масштаб 1:50…1:5000, план занимает ≥ 50 % поля
- [ ] ни одна подпись не пересекает рамку/штамп
- [ ] диаметры подписаны один раз на цепочку
- [ ] домысленное — на слое `ASSUMED` + в примечаниях
- [ ] примечания и спецификация поместились в колонку
- [ ] DWG открывается, слои названы осмысленно
- [ ] PDF того же размера, что лист, и читается
- [ ] PNG пригоден для вставки в письмо/мессенджер

## Если что-то не так

| Симптом | Правка |
|---|---|
| план мелкий в углу | убрать `mm_per_px`, добавить `specification[].length_m` |
| план вылез за рамку | `--scale` крупнее, или проверить выброс координат |
| текст налезает | короче `labels[].text`, больше `height` у подписи |
| легенда не влезла | сократить `legend` или взять лист крупнее |
| пустой PDF | смотреть PNG; PDF строится из той же сцены |
| DWG нет | `doctor`, `NS_OCS_EXE`, права на папку output |
