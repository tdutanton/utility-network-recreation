# Черчение листа по ГОСТ 2.104-2006

## Когда применять

* Нужно нарисовать/проверить рамку и основную надпись (штамп) 185×55.
* Нужно повернуть лист: A3-альбом → A4-портрет для печати.
* Нужно воспроизвести оформление `examples/gas/1` (газовые исполнительные
  схемы) или проверить, почему генератор «не похож».
* Нужно поставить аннотации исполнительной схемы: номера швов, опоры,
  цепи `СШ`/`ОП`, выноски на полке, итоговый блок.

## Быстрый выбор пути

| Ситуация | Путь |
|---|---|
| Нужен чистый лист/шаблон, много вариантов | скрипт `scripts/gost_sheet.py` |
| Чертёж уже открыт в Open CAD Studio | `mcp__ocs__*`, координаты из references |
| Нужен лист внутри NetSketch | готово: `netsketch/gost_sheet.py` + `layout.build_schematic_scene`; проверить `python tools\gost_verify.py` |
| Нужен готовый пример для глаз | `python scripts/gost_sheet.py --demo --out sheet --png --pdf` |

В NetSketch шаблон уже перенесён (не переписывайте вручную): A3-альбом,
оба угла, печать A4 через `print_transform()`. Скрипт ниже полезен для
отдельных листов и для сверки с эталоном.

## Лист: база

| Параметр | A4 | A3 |
|---|---|---|
| Размер, мм | 210×297 | 297×420 |
| Альбом | 297×210 | 420×297 |
| Поля | слева 20, остальные 5 | слева 20, остальные 5 |
| Внутренняя рамка | 185×287 (портрет) | 395×287 (альбом) |
| Штамп | 185×55 | 185×55 |

Координаты в миллиметрах бумаги, начало — левый нижний угол листа.
Всегда рисуйте **в мм листа**, не в метрах и не в единицах модели: иначе
PDF получится пустым или микроскопическим.

## Штамп 185×55: сетка

Локальные координаты, левый нижний угол штампа — (0,0).

```
0                    65                         185
+---------------------+--------------------------+ 55
| 4 пустые строки     |  ШИФР (3,5)              |
| заголовок изменений |  АДРЕС (2,86)            |
| РАЗРАБОТАЛ и подп.  |  ОБЪЕКТ (1,43) | СТАДИЯ  |
|                     |  НАЗВАНИЕ (1,9)| ОРГ.    |
+---------------------+--------------------------+ 0
```

* Левая часть 65 мм: `Изм. | Кол.уч. | Лист | № док. | Подп. | Дата`;
  ниже — `Разработал`, `Проверил`, `ГИП`, `Н. контроль`.
* Правая часть 120 мм: шифр, адрес, объект, `Стадия | Лист | Листов`,
  название чертежа (3 строки), организация + город.
* Точные линии и координаты текста — `references/observed-gas-template.md`.
* Внешний контур штампа 0,6 мм; внутренние линии 0,18–0,25 мм;
  текст 2,5 / 3,5 / 2,86 / 1,9 / 1,43 мм.

## Угол штампа

* По умолчанию — **нижний правый** угол внутренней рамки.
* Если правый низ занят чертежом/легендой — **нижний левый**.
* Штамп всегда прижат к нижней линии рамки; отступ слева 0 или справа 0.
* Нельзя ставить штамп поверх линий, текста и выносок.

В эталонах: фасад — штамп слева, квартиры — справа. Это не два разных
шаблона, а выбор свободного угла.

## Поворот

### A4-портрет с вертикальным штампом (форма 2)

* Штамп 185×55 повернуть на 90° против часовой стрелки: 185 идёт вверх,
  55 — влево-вправо; текст читается снизу вверх.
* Поставить в левый нижний угол: `x=20…75`, `y=5…190`.
* Внутренняя рамка A4-портрета: `(20,5)-(205,292)`.

### A3-альбом → A4-портрет для печати

Эталонные PDF — это A3-альбом, повёрнутый на **90° по часовой стрелке**
и вписанный в A4-портрет (≈0,707). В результате:

* горизонтальный текст становится вертикальным и читается **сверху вниз**;
  чтобы прочитать, поверните лист против часовой стрелки;
* штамп слева внизу A3 → слева вверху A4; справа внизу A3 → слева внизу A4;
* страница PDF — 210×297, а не 420×297.

Не масштабируйте текст отдельно от геометрии: поворачивается весь лист.

Формула для PDF (y вверх, начало листа в левом нижнем углу):

```
s = min(210 / H, 297 / W)          # для A3: 0.7071
x' = y * s
y' = (W - x) * s
page = (210, 297)
```

## Скрипт

```powershell
$env:PYTHONPATH = "$PWD\.pydeps"
$env:MPLCONFIGDIR = "$PWD\.cache\matplotlib"

# A3-альбом, штамп справа, DXF+PDF+PNG и печатный A4-портрет
python skills\gost-drafting\scripts\gost_sheet.py --demo --out out\sheet `
  --dxf --pdf --png --print-a4

# штамп слева
python skills\gost-drafting\scripts\gost_sheet.py --demo --stamp left --out out\sheet_left --png

# A4-портрет, вертикальный штамп (форма 2)
python skills\gost-drafting\scripts\gost_sheet.py --demo --format A4 `
  --orientation portrait --stamp vertical --out out\a4 --png

# свои поля
python skills\gost-drafting\scripts\gost_sheet.py --fields fields.json --out out\sheet
```

  "stage": "ИД",

  "total": "9",

Скрипт зависит только от `ezdxf` и `matplotlib`. Для DXF используется
стиль `GOST` (Arial), для PDF/PNG — Arial с fallback на DejaVu Sans;
итоговый блок — Times New Roman Italic (если установлен).

## Ручной путь через Open CAD Studio

1. `ocs_sessions` → `session_id`; закрыть модальные окна.
2. `ocs_new`.
3. `ocs_execute` → `entities_create` для рамки: два прямоугольника
   `(0,0)-(420,297)` и `(20,5)-(415,292)`.
4. Штамп — 20–30 линий + текст; удобнее собрать один раз в DXF
   скриптом и открыть `ocs_open`, чем перебивать координаты вручную.
5. `ocs_render` с `view: "region"` и `bounds` вокруг штампа — смотреть
   картинку.
6. `ocs_save_verified` в абсолютный путь; `plot` A3 1:1.
7. Для A4-печати повернуть весь лист на 90° по часовой и вписать;
   не просить OCS «сделать PDF» из A3 в A4 без явного масштаба.

## Аннотации исполнительной схемы

Кратко; полные правила — `references/annotations.md`.

* **Шов** — наклонный штрих поперёк трубы + номер (1…37, 2.1…2.17).
* **Опора** — `×`; расстояния — `ОП 3000`.
* **Цепь** — `СШ 1000` / `ОП 3000` над размерной линией; на диагонали
  текст вдоль линии.
* **Выноска** — полка + линия к символу: `Отвод Ø57`, `Тройник Ø32`,
  `Переход Ø25/20`, `Заглушка Ø57`, `Кран Ø25`, `КИП Ø25`.
* **Диаметр** — `Ø25`, `Ø57`; один раз на участок.
* **Отметка** — `Отм. -0.8` с полкой.
* **Квартира** — `КВ. 5`, `1 под.`; крупно, без выноски.
* **Итог** — `Наружный газ-д l= 2,5 м`, `Внутренний газ-д`,
  `ст.д.25 l= 3,5 м`, `Итого 9,2 м`; Times Italic, крупно.
* **Легенда** — `30 - номер сварного шва`, `× - опора…`, `□ - футляр`.

В DXF `Ø` пишите как `%%C`; `СШ`/`ОП` — прописными; в легенде авторы
пишут строчными `оп`/`сш` — это допустимо, но в размерах только `СШ`/`ОП`.

## Проверка перед выдачей

- [ ] A3-альбом: 420×297; рамка 20/5; внешний контур есть.
- [ ] Штамп 185×55, прижат к нижней рамке, не пересекает чертёж.
- [ ] Поля штампа совпадают с эталоном; шифр/адрес/стадия/лист/листов.
- [ ] Текст не пересекает линии; подписи не налезают друг на друга.
- [ ] PDF A3 — 420×297; печатный PDF — 210×297 и повёрнут.
- [ ] `Ø` рендерится, кириллица не квадратами.
- [ ] DWG открывается; слои `FRAME/STAMP/TEXT` (или эталонные).
- [ ] Для схемы: номера швов уникальны, опоры не дублируются,
      итог сходится с суммой длин.

## Грабли

* **A4 vs A3.** Не определяйте формат по PDF: PDF — A4-портрет, DWG —
  A3-альбом. Проверяйте по штампу 185 мм.
* **Штамп не всегда справа.** В эталонном фасаде он слева; не «исправляйте»
  это на правый, если правый низ занят.
* **Поворот.** PDF — это поворот всего A3 на 90° по часовой, а не
  отдельный A4-шаблон. Текст и линии поворачиваются вместе.
* **Единицы.** Всё в мм бумаги; не рисуйте 420 «метров».
* **Шрифт.** `SHTAMP`/`PROFIL` — SHX, в matplotlib могут не отрисоваться;
  для PDF используйте TTF (Arial/DejaVu), для DWG — стиль `GOST`.
* **`save_verified` и `plot`** по существующему пути могут открыть диалог
  подтверждения; удаляйте файл до вызова.
* **BOM в JSON.** Читайте `utf-8-sig`.
