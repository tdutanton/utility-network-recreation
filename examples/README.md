# Примеры: эскиз → готовый чертёж

Эта папка — обучающая выборка проекта. По ней настраивается и распознавание,
и оформление.

## Структура (как у вас сейчас)

```
examples/
  gas/
    1/                        объект
      input/                  эскизы: 01_Фасад.jpg, 02_кв1_5.jpg, …
      result/
        dwg/                  1_фасад.dwg, 2_кв1_5.dwg, …
        pdf/                  1_фасад.pdf, …
        jpg/                  1_фасад_page-0001.jpg, …
      models/                (появится) разбор эскиза для few-shot
        2_кв1_5.json
  heat/
    1/
      input/draft_page-0001.jpg
      result/plot_dwg.dwg, plot_jpg.jpg
```

Допустимы оба варианта `result/`: плоско (`result/*.dwg`) и по форматам
(`result/dwg`, `result/pdf`, `result/jpg`). Эскизы и чертежи сопоставляются
по имени: `02_кв1_5.jpg` ↔ `2_кв1_5.dwg` ↔ `2_кв1_5_page-0001.jpg`.

## Что делает индексатор

```powershell
$env:PYTHONPATH = "$PWD\.pydeps"
python tools\index_examples.py --verbose
```

1. Находит пары «эскиз ↔ DWG» (включая вложенные папки форматов).
2. Конвертирует каждый DWG в DXF через Open CAD Studio.
3. Вытаскивает профиль: слои и их цвета, блоки (`shtamp_b28`, `usl_*`, `ved`),
   типы сущностей, надписи, реквизиты штампа, формат листа из PDF.
4. Пишет `examples/index.json`. Профиль подмешивается в промпт распознавания.

Текущий результат: 10 пар, газ — A3-альбом (печатный PDF — A4-портрет
с поворотом), тепло — A3.

## Зачем `models/*.json`

Один аккуратно собранный разбор эскиза стоит десяти сканов: он идёт в промпт
как образец «такой эскиз → такая структура». Пример:
`examples/gas/1/models/2_кв1_5.json` — схема из 4 участков, 6 элементов,
легенда, спецификация и итоговые блоки длин.

Достаточно 5–10 таких файлов, чтобы распознавание стало стабильным.

## Наблюдения по оформлению

Подробности — в `knowledge/style-observed.md`: штамп 185×55 в нижнем
углу (в PDF выглядит вертикальным из-за поворота листа), поля
`Разработал/Проверил/ГИП/Н.контроль`, стадия `ИД`, шифр
`09/11ПР-2026-ИОС6`, слои `TR_UP/TR_DN/SN/BL/газ/Трубы`, легенда строками
«символ — пояснение», итоговые блоки «Наружный газ-д Ø25 L=2,5 м».

## Приватность

Всё локально. В облачную модель уходят только изображение эскиза и текст
промпта — без ваших DWG и имён файлов.
