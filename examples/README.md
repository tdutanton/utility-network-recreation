# Примеры: эскиз → готовый чертёж

Эта папка — «обучающая выборка» проекта. По ней настраивается и распознавание,
и оформление. Чем больше ваших пар, тем точнее результат.

## Структура

```
examples/
  gas/                 тип сети (heat, gas, дальше — любой новый)
    01/                номер примера
      input/           сканы эскизов: .jpg .png .pdf
      result/          ваши готовые чертежи: .dwg (можно .dxf)
      model.json       (необязательно) разобранная семантика эскиза
      notes.md         (необязательно) что важно в этом примере
    02/
      ...
  heat/
    01/ ...
```

Требования минимальные: `input/` и `result/` с одинаковым номером — уже пара.
Названия файлов внутри значения не имеют.

## Как это используется

1. `python tools/index_examples.py` проходит по папкам, конвертирует ваши DWG
   в DXF (через Open CAD Studio) и собирает `examples/index.json`:
   * слои и их цвета/типы линий;
   * используемые блоки, шрифты, размерные стили;
   * примеры надписей (в том числе штамп, примечания, легенду);
   * габариты чертежа и единицы.
2. Профиль попадает в промпт распознавания — модель видит, какими терминами
   и какой структурой вы пользуетесь.
3. `model.json` (если положить) идёт в промпт как few-shot пример:
   «такой эскиз → такая модель». Это самый сильный сигнал для модели зрения.

## Что даёт лучший результат

* **Пары, а не одиночные файлы.** Эскиз без результата почти не помогает.
* **`model.json` для 5–10 примеров.** Достаточно грубого, вручную собранного
  описания: узлы, участки, диаметры, элементы, подписи. Это резко повышает
  стабильность распознавания.
* **Разные почерки и качество сканов** — чтобы модель не цеплялась за один вид.
* **`notes.md`** — одна-две строки: «здесь важно, что диаметры в мм,
  а длины в метрах», «двухтрубная прокладка».

## Приватность

Всё лежит локально. В облачную модель уходят только изображение эскиза и
текст промпта, без ваших DWG и без имён файлов.

## Быстрый старт

```powershell
python tools\index_examples.py
python -m netsketch doctor
```
