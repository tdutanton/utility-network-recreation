# Общие правила: рукописный эскиз → чертёж сети

Этот файл читают и человек, и модель распознавания. Он задаёт словарь,
которым описывается эскиз, и правила, по которым из описания получается лист.

## 1. Что считается эскизом

Скан или фото листа, на котором от руки нарисована трасса/схема сети:
ломаная линия (или несколько), подписи диаметров (`Ø57`, `d57`, `Ду50`),
длины (`5500`, `L=24,0`), номера колодцев/камер (`кол. 5`, `ТК-1`), номера
пикетов, отметки, выноски с номерами и таблица «Условные обозначения».

Допустимы: мятая бумага, синяя/чёрная ручка, цветные пометки, зачёркивания,
стрелки, обрыв линии за границей листа.

## 2. Словарь элементов

| Канон | Русская подпись | Как выглядит на эскизе |
|---|---|---|
| `valve` | Задвижка | «бабочка» из двух треугольников на линии |
| `valve_ball` | Кран шаровой | кружок + треугольники, «кран» |
| `filter` | Фильтр | ромб на линии, «фильтр» |
| `flowmeter` | Расходомер | кружок с диагоналями, «расходомер», «РС» |
| `compensator` | Компенсатор | П-образный или петлевой излом |
| `support` | Опора | поперечная черта со штриховкой |
| `well` | Колодец / камера | квадрат или кружок, «кол.», «ТК» |
| `gpsh` | ГРПШ / ГРУ | прямоугольник, «ГРПШ», «ГРУ» |
| `sleeve` | Футляр | две параллельные линии вокруг трубы |
| `hydrolock` | Гидрозатвор | П-образный сифон |
| `tee` | Тройник / врезка | точка на линии, отвод |
| `cross` | Крестовина | пересечение с точкой |
| `reducer` | Переход | трапеция, «перех. Ø25/20» |
| `flange` | Фланец | две короткие черты |
| `coupling` | Муфта | две черты/скобки, «муфта» |
| `insulation_end` | Концевая изоляция | крест на трубе |
| `manometer` | Манометр | кружок со стрелкой |
| `regulator` | Регулятор давления | «бабочка» + кружок, «РД» |
| `meter` | Узел учёта | рамка, «УУ» |
| `inlet` | Ввод | стрелка к объекту |
| `outlet` | Выпуск | стрелка от объекта |
| `pit` | Ковер | квадрат с диагональю |

Если обозначение не опознано — `unknown`, элемент всё равно переносится на
лист с пометкой и попадает в примечания. Молча выбрасывать нельзя.

## 3. Координаты и калибровка

Координаты — в пикселях исходного изображения, ось Y вниз.
Калибровка (`mm_per_px`) берётся из двух точек с известным размером
(например, участок «5500»). Если калибровки нет, но в эскизе есть
ведомость длин, масштаб считается по сумме длин и длине линии в пикселях.
Если нет ни того, ни другого — масштаб условный, это `ASSUMED`.

## 4. Достоверность

* `CONFIRMED` — прочитано с эскиза однозначно;
* `DERIVED` — вычислено (длина по калибровке, диаметр по ведомости);
* `ASSUMED` — домыслено (высота, глубина, материал, недостающий диаметр).

`ASSUMED` выносится на слой `ASSUMED`, перечисляется в примечаниях и в
`assumptions`. В основные слои такие данные не попадают.

## 5. Геометрия трассы

Труба — не кисть: на чертеже допустимы только **прямые участки** и
**повороты 90°**. Рукописная линия всегда дрожит, поэтому перед черчением
трасса нормализуется (`netsketch/route.py`):

1. лист выравнивается, если эскиз повёрнут на пару градусов;
2. ломаная упрощается — убираются точки, не образующие угол;
3. газовые схемы доводятся до ортогональной «монтажной» схемы: все
   повороты 90°, близкие оси сливаются в одну;
4. тепловые трассы сохраняют настоящие диагонали — там ломается только
   дрожание, а не проектный уклон.

Проверено по эталонным DWG: в газовых схемах 37 из 39 длинных линий идут
строго под 0° или 90°.

## 6. Оформление листа

* Газовые исполнительные схемы — A3-альбом 420×297; печатный PDF —
  A4-портрет 210×297 (A3 повернуть на 90° по часовой, вписать ≈0,707).
* Рамка: слева 20 мм, остальные 5 мм.
* Основная надпись 185×55 мм — в свободном нижнем углу (слева или справа),
  прижата к рамке.
* Схемы сварных соединений — без масштаба; легенда и итоговый блок —
  в свободной стороне листа, без таблиц «Спецификация»/«Примечания».
* Для планового режима масштаб подбирается из ряда 1:50…1:5000 так,
  чтобы план заполнил поле.
* Подписи диаметров — 2,2 мм, вдоль линии; размеры — 2,0–3,0 мм;
  номера швов — 3,5 мм.
* Итог: `Наружный газ-д l= …`, `Внутренний газ-д …`, `Итого …`.

Подробный шаблон — `knowledge/style-observed.md` и скилл `gost-drafting`.

## 7. Чего делать нельзя

* Придумывать диаметры, длины и отметки без пометки ASSUMED.
* Рисовать изогнутые трубы: только прямые участки и повороты 90°.
* Терять прочитанные подписи: каждая должна попасть на лист или в примечания.
* Рисовать вместо плана «красивую» схему, не совпадающую с эскизом.
* Ставить текст поверх линий и рамки.
