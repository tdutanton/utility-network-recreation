# Газ: эталон → что делать, чтобы получались такие же листы

Основание: `examples/gas/1` — 9 эскизов и 9 готовых листов. Подробный
разбор оформления — `knowledge/style-observed.md`. Здесь — выводы и план.

## 1. Главный вывод

Сейчас NetSketch строит **план/схему в масштабе** на A4-портрете со своей
упрощённой рамкой, колонкой «Условные обозначения / Спецификация /
Примечания» иgeneric-подписями. Эталоны — другой жанр:

> **исполнительная схема сварных соединений** на A3-альбоме, с
> ГОСТ-штампом 185×55, номерами швов, опорами, цепями `СШ`/`ОП`,
> выносками на полке и итоговым блоком длин.

Поэтому «подкрутить шрифт» недостаточно. Нужен второй режим генерации —
`schematic` (исполнительная схема) — с отдельным шаблоном листа и
отдельным аннотационным движком. Плановый режим можно сохранить для
других задач.

## 2. Целевой лист в двух словах

* A3-альбом 420×297; рамка 20/5; внешний контур по краю.
* Штамп 185×55 в свободном нижнем углу (слева или справа).
* PDF для печати — A4-портрет: A3 повернуть на 90° по часовой,
  вписать (≈70,7 %).
* Чертёж — в свободном поле; легенда и итоговый блок — в свободной
  стороне; без таблиц «Спецификация» и «Примечания».
* Аннотации: номера швов, `×` опор, цепи `СШ`/`ОП`, выноски элементов,
  диаметры, отметки, квартиры, итоговый блок.

## 3. Разрывы: что есть → что нужно

| Узел | Сейчас | Нужно |
|---|---|---|
| Формат | A4-портрет (модель) | A3-альбом; A4-портрет только как печатный PDF |
| Рамка | 20/5, одна | 20/5 + внешний контур 420×297 |
| Штамп | своя форма ~185×55, поля «Организация», «Масштаб» | точная сетка 65+120, шифр, адрес, объект, стадия/лист/листов, подписи |
| Угол штампа | всегда справа снизу | свободный нижний угол (слева/справа) |
| Композиция | правая колонка легенды/спеки/примечаний | свободное поле: чертёж + легенда + итоговый блок |
| Трасса | ортогональная, прямые углы | фасад — прямые + диагональ; квартиры — скруглённые повороты/врезки |
| Швы | нет | номера 1…37 / 2.1…2.17, штрих на трубе |
| Опоры | нет | `×`, расстояния `ОП` |
| Размеры | общая цепь | цепи `СШ`/`ОП` с префиксами, текст над линией |
| Выноски | линия + текст | полка + линия к символу, `Ø` через `%%C` |
| Итоги | `notes` | крупный блок «Наружный/Внутренний/Итого» |
| Шрифты | DejaVu/Arial | Arial + Times New Roman Italic для итогов |
| Слои/блоки | `GAS_*` | `Трубы`, `ГП_Таbлицы`, `анп Рамка жирная`; блоки `shtamp_b28`, `ved`, `usl_*` — опционально |
| PDF | A4 из рендера | A3-альбом + A4-портрет с поворотом |

## 4. План по фазам

### Фаза 0. Зафиксировать факты (сделано)

* Исправлены `knowledge/style-observed.md` и допущения об A3/штампе.
* Создан скилл `gost-drafting` с точной сеткой штампа и скриптом
  `scripts/gost_sheet.py`.
* Скрипт проверен: A3-рамка + штамп, оба угла, A4-портрет с поворотом.

### Фаза 1. Шаблон листа в проекте

Файл: новый `netsketch/gost_sheet.py` (или расширение `sheets.py`).

* A3-альбом по умолчанию для `network_type=gas` в режиме `schematic`.
* Точная сетка штампа из `skills/gost-drafting/references/observed-gas-template.md`.
* Поля: `cipher`, `address`, `object`, `stage`, `sheet`, `total`,
  `organization`, `developer/checker/gip/ncontrol`, `date`, `drawing`.
* Угол штампа: `left|right`; выбор по свободному месту.
* Печать: A3 PDF 1:1 + A4-портрет (поворот 90° по часовой, 0,707).
* Текст: Arial; итоговый блок — Times New Roman Italic.

Приёмка: координаты сетки совпадают с эталоном ±0,2 мм; текст не
пересекает линии; PDF A4 — 210×297; A3 — 420×297; DWG открывается.

### Фаза 2. Композиция листа

Файл: `layout.py` (новый `build_schematic_scene`).

* Считать bbox чертежа и bbox текстовых блоков.
* Выбрать свободный нижний угол под штамп.
* Разместить легенду и итоговый блок в свободной стороне.
* Не допускать пересечений; если не влезает — уменьшить/перенести,
  но не наезжать на рамку.
* Никакой правой колонки-таблицы в этом режиме.

Приёмка: на 9 эталонных листах автоматическая раскладка даёт тот же
угол штампа и ту же сторону текста (фасад — слева/справа, квартиры —
справа), без пересечений.

### Фаза 3. Аннотационный движок

Файл: новый `netsketch/annotations.py`.

Реализовать примитивы и правила:

1. `weld_marks(points, numbers)` — штрих поперёк трубы + номер
   (суффиксы `.1`, `.2` для веток).
2. `support_marks(points)` — `×`.
3. `dimension_chain(points, values, prefix="СШ"|"ОП"|"")` — размерная
   цепь с текстом над линией, выносными линиями, засечками; для
   диагонали — aligned.
4. `callout(target, text, side)` — полка + линия + текст; `Ø` → `%%C`.
5. `level_mark(target, text)` — `Отм. -0.8` с полкой.
6. `room_label(point, text)` — `КВ. 5`, `1 под.`.
7. `summary_block(lines)` — итоговый блок крупным курсивом.
8. `legend(rows)` — символ + пояснение без рамки.

Правила: текст не на трубе; выноски не пересекаются; номера швов не
дублируются; расстояния в мм; `СШ`/`ОП` — прописными.

Приёмка: на `01_Фасад` воспроизводятся 37 номеров швов, 23 `СШ`, 23 `ОП`,
выноски элементов и итоговый блок; на `02_кв1_5` — 17 номеров,
18 выносок, легенда, итог 9,2 м.

### Фаза 4. Схема модели

Файл: `model.py`, `references/model-schema.md`.

Добавить (обратно совместимо):

```json
{
  "mode": "schematic",
  "sheet": {"format": "A3", "orientation": "landscape", "stamp": "auto"},
  "welds": [{"id": "1", "x": 0, "y": 0}, {"id": "2.1", "x": 0, "y": 0}],
  "supports": [{"x": 0, "y": 0}],
  "chains": [{"kind": "weld", "points": [[0,0],[1,0]], "values_mm": [1000]}],
  "callouts": [{"text": "Отвод Ø57", "target": [0,0], "side": "left"}],
  "rooms": [{"text": "КВ. 5", "x": 0, "y": 0}],
  "summary": ["Наружный газ-д l= 2,5 м", "..."],
  "legend": ["30 - номер сварного шва", "..."]
}
```

Старые поля (`segments`, `elements`, `labels`, `notes`) не ломать.
`title` дополнить `cipher`, `object`, `date`, `gip`, `ncontrol`.

Приёмка: `examples/gas/1/models/2_кв1_5.json` переписывается в новую
схему и собирается без потери подписей.

### Фаза 5. Распознавание

Файлы: `prompts.py`, `knowledge/gas.md`, `recognize.py`.

* Просить у модели: номера швов, опоры, цепи, выноски, квартиры,
  итоговые длины, реквизиты штампа.
* Few-shot: 2–3 пары «эскиз → model.json» (01_Фасад, 02_кв1_5, 03_кв2_6).
* Не считать размерную цепь второй трубой; не терять суффиксы `.1`.
* Отдельно проверять `Ø` vs `0`, `СШ` vs `СП`, `ОП` vs `0П`.

Приёмка: на 9 эскизах номера швов и итоговые длины совпадают с эталоном
(допуск — ручная правка 1–2 подписей).

### Фаза 6. Рендер и QA

* `render.py`: A3/A4, Arial, Times Italic, толщины 0,25/0,5/0,7.
* `dxfout.py`: слои `Трубы`, `ГП_Таbлицы`, `анп Рамка жирная`, `0`;
  блоки `shtamp_b28`, `ved`, `usl_*` — по возможности.
* `qa.py`: проверка рамки/штампа/пересечений; инвентарь подписей;
  сравнение с эталоном по PNG (side-by-side / overlay).
* `tools/smoke_test.py`: A3-газ, A4-печать, DWG открывается.

## 6. Что нужно уточнить у пользователя

1. **Печать.** Всегда A3-альбом DWG + A4-портрет PDF, или бывают A3 PDF?
2. **Штамп.** Всегда 185×55 в свободном углу, или есть фиксированный
   шаблон/блок `shtamp_b28`, который надо вставлять?
3. **Реквизиты.** Брать `09/11ПР-2026-ИОС6` / `ООО "Новгородаудит-ЭНЕРГО"` /
   `Евгеньев А.А.` как константы объекта или из формы?
4. **Стиль схем.** Скруглённые повороты обязательны или допустимы прямые
   (как в фасаде)?
5. **Приоритет.** Сначала шаблон листа (фаза 1–2) или сразу аннотации
   (фаза 3) на одном листе `02_кв1_5`?
