## Сессия 16.11.2026: тепловой лист heat/1

* `meta.no_orthogonalize = true`. Модель уже в мм листа; `route.orthogonalize`
  для heat выбирал режим `iso` и крутил весь план на 13,6° — лист переставал
  быть похож на исходный. Теперь координаты плана не трогаем.
* **План в `placement: absolute` больше не переворачивается.** В `build_scene`
  координаты absolute раньше шли через пиксельный `Transform.pt`, который
  делает `y = y1 - p.y`; тепловой лист вставал «с ног на голову» (П-образная
  трасса уезжала вниз). Теперь для absolute используется `IdentityTransform`,
  масштаб 1:1. Именно это развернуло лист правильно.
* **Трубы — из ВСЕХ линий слоя «Трубы»**, включая `short_lines` (короткие
  ветки/опуски): `pipes` + `short_lines` → 588 участков. Склейка только
  коллинеарных цепочек (8°, 0,7 мм); ветки и повороты остаются отдельными,
  поэтому ничего не «стягивается в вилку». Слой `0` — штрихи символов,
  в трубы больше не попадает.
* **Задвижки — из пар треугольников** (`triangles`): две половинки с общим
  остриём, базы напротив, размер 3–5 мм. Получилось 184 шт., размер 0,4
  (≈3,2 мм на листе).
* **Фильтры — ромбы из 4 коротких линий** слоя «Трубы» (2 шт.): 4-цикл,
  стороны 2–4 мм; их линии исключаются из труб, чтобы ромб не задваивался.
* `meta.defect_table_at = [412, 290]` — справа сверху «Ведомость дефектов
  по подъездам»: строки — коды 2/7/12/13/14/15/17, столбцы 4/3/2/1, итог 130.
  `notes_at` отключён: описания дефектов теперь в таблице.
* На плане дефект — маркер (кружок 1 мм с точкой), без номера; маркер
  прижимается к ближайшей оси трубы (допуск 8 мм).
* При абсолютных блоках `layout` больше не резервирует правую колонку и
  отрезает верхнюю полосу под легенду/таблицу; иначе план был сжат влево.
* `tools/heat_check.py` — маркеры, отсутствие номеров, таблица, арматура,
  рамка/штамп, чтение DWG. PNG просмотрен; DWG читается (2880 сущностей).
* Финальный прогон: `heat_check.py`, `smoke_test.py`, `gost_verify.py`,
  `callout_check.py` — зелёные; все 13 DWG (12 газ + тепло) читаются
  обратно Open CAD Studio.

## Команды

```powershell
$env:PYTHONPATH = "$PWD\.pydeps"
$env:PYTHONIOENCODING = "utf-8"
$env:MPLCONFIGDIR = "$PWD\.cache\matplotlib"

python -m netsketch build <model.json> --out output --stem <имя> [--no-dwg]
python tools\smoke_test.py
python tools\gost_verify.py
python tools\callout_check.py                     # выноски: излом/полка/острие + эталон
python tools\enrich_callout_elbows.py [--write]   # дополнить модели elbow из .cache/etalon-dxf
python tools\heat_check.py                        # тепловой лист: маркеры/ведомость/рамка/DWG
```

DWG → DXF: `netsketch.dwg.find_ocs()` + `_run(ocs, ["--export", dwg, dxf])`.
Спека листа (нормировка в мм A3): `.cache/etalon-spec/extract.py` (список `SHEETS`).
Спека → модель (квартирные схемы): `python tools/sheet_model.py --spec ... --out ... --sheet N --source ...`.
Тепло: `.cache/etalon-spec/to_heat_model.py`.

## Правила, которые уже стоили времени

* Масштаб на схемах **не печатать** (`scale_text = ""`).
* Штамп — 185×55 справа внизу (как в газе), для тепла тоже.
* Выноски: острие — из `context.leaders[].lines[].vertices` (там ОДНА точка),
  излом — `last_leader_point`, текст — из `context.mtext.insert`;
  `virtual_entities` даёт ещё и подчёркивание текста, по нему привязываться нельзя.
  Если брать вершины из virtual/proxy, `targets` уезжают на излом — так и было
  в старых моделях gas/1–4 (исправлено `tools/enrich_callout_elbows.py`).
* `x`/`y` выноски — ВЕРХНИЙ угол текста (`align` = left/right), а не конец полки;
  у фасада gas/1 раньше был конец полки (исправлено).
* **Тепловой план — уже в мм листа.** `meta.no_orthogonalize = true`: иначе
  `route.orthogonalize` для heat выбирает `iso`, крутит план на 13–14° и лист
  перестаёт быть похож на исходный.
* **Дефекты тепла — маркеры + ведомость.** 130 номеров заменены маркерами,
  справа «Ведомость дефектов по подъездам» (коды × 4/3/2/1). Маркер прижимается
  к оси трубы (8 мм), иначе висит в пустоте; группировка — по x-полосам подписей
  «N подъезд» (стояки в модели не выделены).
* **Абсолютные блоки не резервируют правую колонку.** Если у модели есть
  `legend_at`/`defect_table_at`, план получает всю ширину, а верхняя полоса под
  блоки отрезается; иначе план сжимается влево и налезает на таблицу.
* Засечки швов бывают на 130° (зеркальные листы) — нормализовать угол к `[-90, 90)`.
* Счётчик/футляр — маленькие прямоугольники на трубе (гориз. → `flowmeter`, верт. → `sleeve`).
* Детали и грабли — в `AGENTS.md`.
